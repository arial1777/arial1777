# 画像生成プロンプト（GPT用）

ヒーローと背景を差し替えるための素材。そのままコピペして使える形にしてある。

## 先に決めておきたいこと

**立ち絵は生成し直さないほうがいい。** GPTは同じキャラクターを完全に再現できないので、
設定シートの顔・髪型・スーツと微妙にずれた別人が出る。おすすめは**背景だけを生成して、
既存の立ち絵を上に重ねる**構成。キャラの同一性が保てるうえ、背景と人物を別レイヤーに
できるので、あとから位置や大きさを自由に調整できる。

どうしても人物込みのバナーが欲しい場合は §4 に別プロンプトを用意した。

**ChatGPTの画像生成は 1024×1024 / 1536×1024（横長）/ 1024×1536（縦長）の3サイズしか出ない。**
それ以上の解像度は出ないので、横長は 1536×1024 で作ってこちらで切り出す。背景は輪郭の
はっきりした絵ではないので、多少拡大しても破綻しない。

**性能上の制約（これが可読性にも効く）。** ヒーロー背景はLCP要素になるので、AVIFで
150KB以下に収めたい。暗くて情報量の少ない絵ほど軽くなるので、「左側を暗く空ける」という
指示は、文字を読みやすくすると同時にファイルを軽くする指示でもある。派手にしないほうが
両方に効く。

## 1. ヒーロー背景（デスクトップ）

- ファイル名: `hero-bg-wide.jpg` ／ 生成サイズ: **1536×1024（横長）**
- 用途: ヒーロー全面の背景。この上に白い見出しと立ち絵を重ねる

```
夜の水面を、やや斜め上から見た抽象的で静かな背景画像を描いてください。

【色】
深い紺色 #091434 を基調に、青 #1042BE から水色 #2288E2、#3AD1FC への
なめらかなグラデーション。全体的に暗く、彩度は抑えめ。

【構図】
・画面の右上に、月のように発光する光の輪をひとつ置く
・その光が水面に落ちて、同心円の波紋が静かに広がっている
・水面には薄い霧と、浮かんでいる小さな光の粒子
・水しぶきと水滴を少しだけ、右側に寄せて配置
・青く半透明の音符（八分音符とト音記号）を、光の輪のまわりに漂わせる。
　ただし多くても5個まで。主張させない
・画面の左側60%は暗く、情報量を落とす。白い文字を載せる余白なので、
　模様・強い光・細かいディテールを置かない

【画風】
アニメーションの背景美術。透明感のある水彩とデジタルの中間。
シネマティックで静か。派手さより余白を大事にする。

【禁止】
人物を描かない。文字・ロゴ・記号・透かしを一切描かない。
中央に主役となるオブジェクトを置かない（背景として使うため）。
```

## 2. ヒーロー背景（モバイル）

- ファイル名: `hero-bg-tall.jpg` ／ 生成サイズ: **1024×1536（縦長）**
- 用途: スマホのヒーロー背景。横長を切り出すと構図が死ぬので別に作る
- **注意**: モバイルは画面上部に見出しが来るので、空けるのは上側

```
夜の水面を見下ろした、縦長の静かな背景画像を描いてください。

【色】
深い紺色 #091434 を基調に、青 #1042BE から水色 #2288E2、#3AD1FC への
なめらかなグラデーション。全体に暗く、彩度は抑えめ。

【構図】
・画面の上から45%は、ほぼ均一な暗い紺色にする。
　白い文字を載せる余白なので、模様も光も置かない
・光の輪（月のような発光する円）は、画面の中央よりやや下に置く
・そこから同心円の波紋が下に向かって広がる
・水面の霧、浮遊する小さな光の粒子、少量の水しぶき
・青く半透明の音符を3個程度だけ、光の輪の近くに漂わせる

【画風】
アニメーションの背景美術。透明感のある水彩とデジタルの中間。静かで余白が多い。

【禁止】
人物を描かない。文字・ロゴ・記号・透かしを一切描かない。
```

## 3. ページ全体に敷くテクスチャ

- ファイル名: `texture-water.png` ／ 生成サイズ: **1024×1024**
- 用途: サイト全体に不透明度8〜12%で重ねる。のっぺりした暗い面に質感を出すため

```
極めて暗い、ほぼ黒に近い紺色の水面テクスチャを描いてください。

・使う色は #091434 から #0E1D45 の範囲のみ。それ以外の色を使わない
・細かい波紋と、ごく淡い粒子のノイズだけで構成する
・コントラストは極端に低く、模様が主張しないこと。
　遠目には「わずかにざらついた紺色の面」に見える程度
・光源、ハイライト、明るい部分をつくらない
・画面の四隅や端に強い構造を置かない（並べて敷いても継ぎ目が目立たないように）
・正方形

【禁止】
人物・文字・音符・明確な形のあるモチーフを描かない。
```

## 4.（任意）人物込みのヒーローバナー

同一性が落ちるリスクを承知のうえで作る場合。**必ず設定シートかアイコン画像を添付**して、
参照画像として使わせること。添付なしだと確実に別人になる。

- 添付する画像: `image/S__36298756_0.jpg`（アイコン）と `image/S__36298755_0.jpg`（設定シート）
- 生成サイズ: **1536×1024（横長）**

```
添付した画像のキャラクターを、そのままの造形で描いてください。
青い髪、青い瞳、濃紺のスーツにベストと青いシャツ、ト音記号の髪飾り。
髪型・髪色・服装・顔立ちを変えないこと。

【構図】
横長のバナー。
・人物は画面の右3分の1に、腰から上で配置。正面を見ている
・左3分の2は、暗い夜の水面と波紋だけの余白にする。
　白い文字を載せるので、模様や強い光を置かない
・人物の背後に、月のように発光する光の輪
・水面の波紋、浮遊する光の粒子、青く半透明の音符を数個

【色】
深い紺色 #091434 を基調に、青 #1042BE から水色 #3AD1FC のグラデーション。

【画風】
アニメ調のイラスト。透明感のある彩色。シネマティックで静か。

【禁止】
文字・ロゴ・透かしを一切描かない。人物を複数描かない。
```

## 5. できあがったら見るところ

1. **文字が写り込んでいないか。** AIは頼んでいなくても看板や記号を描き込むことがある
2. **左側（モバイルは上側）が本当に空いているか。** ここが埋まっていると見出しが読めない
3. **明るすぎないか。** 白文字とのコントラスト比が4.5:1を切ると可読性が落ちる。
   数値はこちらで計算するので、迷ったら暗いほうを選んでおけばよい
4. **音符が多すぎないか。** 5個を超えると急に子どもっぽくなる
5. 水面の波紋が不自然に途切れていないか

## 6. 渡してもらったあと、こちらでやること

- 必要な比率への切り出しと、デスクトップ／モバイルの出し分け
- AVIF・WebP変換とサイズ最適化（ヒーローは150KB以下を目標）
- 見出しが載る領域のコントラスト比を実測して、必要なら暗いオーバーレイを重ねる
- OGP画像（1200×630）の作り直し
- ヒーローのレイアウトを、背景画像を前提とした構造に変更

生成した画像は `image/` に置いてもらえれば、そこから拾う。

## 7. ろぼとダイブ（/play）の素材 — 生成済み

2026-09-07 に生成して `assets/game/` と `public/game/` に入れたもの。
作り直すときはこのまま使える。原本は `image/` の 00_18_10 / 00_18_41 / 00_19_47。

**透過の作り方**: ChatGPT の出力に透過は乗らないので、**マゼンタ #FF00FF の一色背景**で
出してもらい、こちらで抜いている。この色は arial のパレットにまったく無いうえ、
前景（青と水色）の赤成分がほぼ0なので、混ざり具合から不透明度を解けて縁に紫が残らない。
背景にグラデーションや影が乗ると抜けなくなるので、そこだけ厳しく指定している。

### 7-1. ゲーム内オブジェクト（1枚に6つ）

生成サイズ **1536×1024（横長）**。こちらで6つに切り分ける。

```
ゲームで使う水中のオブジェクトを、1枚の画像に6つ並べて描いてください。

【最重要】
背景は「純粋なマゼンタ #FF00FF」の一色で、完全に塗りつぶしてください。
グラデーション・影・模様・枠線を背景に一切置かないでください。
あとで背景を機械的に抜くので、オブジェクトの中にマゼンタや
ピンク系の色を使わないでください。

【並べ方】
横3列×縦2段の格子に、6つを等間隔で配置。
それぞれの周囲にはマゼンタの余白を十分に空け、互い違いに重ねないこと。

【6つの中身】
1段目
・左: 水中の岩。ごつごつした濃紺の岩塊。横に広がった形
・中: 水中の岩。1つ目より縦に細長く、先が尖った形
・右: 海藻。縦に長い昆布のような葉が3〜4枚、根元から立ち上がっている
2段目
・左: 渦。水が回転してできた輪。中心に向かって渦を巻いている。左右対称の円形
・中: 八分音符。青く半透明に発光している。単体でひとつ
・右: 泡のかたまり。大小の丸い気泡が7〜8個、寄り集まっている

【色】
深い紺色 #091434 と青 #1042BE から水色 #2288E2、#3AD1FC の範囲だけを使う。
岩と海藻は暗め、渦と音符と泡は明るく発光させる。

【画風】
アニメ調のゲーム素材。輪郭線をはっきり描く。小さく表示しても形が読めること。
過度に細かいディテールを入れない。

【禁止】
人物・ロボット・文字・ロゴ・透かしを描かない。
背景に色を足さない。影を地面に落とさない（浮いている前提の素材なので）。
```

### 7-2. 深い海の背景

生成サイズ **1536×1024（横長）**。こちらで左右ミラーして継ぎ目を消し、
横に流して使う（`water-tile.webp` と同じ作り方）。

```
深い水中を横から見た、暗く静かな背景画像を描いてください。

【色】
深い紺色 #091434 を基調に、上へ向かって青 #1042BE、水色 #2288E2 へ
なめらかに明るくなるグラデーション。全体的に暗く、彩度は抑えめ。

【構図】
・画面の上端が水面に近く明るい。下へ行くほど暗く沈む
・水面から差し込む光の柱を、ゆるやかに2〜3本
・浮遊する小さな光の粒子と、ごく淡い霧
・青く半透明の音符を3個まで、遠景に小さく漂わせる。主張させない
・オブジェクトはすべて遠景として薄く描く。
　この上にゲームのキャラクターと障害物を重ねるので、
　中央に主役となる形を置かない
・画面の左端と右端は、明るさと構造を揃えること。
　横に並べて繰り返すので、端に目立つ形を置かない

【画風】
アニメーションの背景美術。透明感のある水彩とデジタルの中間。静かで余白が多い。

【禁止】
人物・ロボット・文字・ロゴ・透かしを描かない。
岩や海藻など、はっきりした形の障害物を描かない（別素材で重ねるため）。
```

### 7-3. ろぼとの差分（噴射中・気絶）

生成サイズ **1536×1024（横長）**。
**必ず `assets/roboto/roboto.png` を添付**して参照させること。添付なしだと
別のロボットになる（§4 と同じ理由）。通常時の絵は元の `roboto.png` をそのまま使う。

```
添付した画像のロボットを、そのままの造形で描いてください。
水色 #3AD1FC のボディ、丸い頭、濃紺の輪郭線。
形・色・顔の作りを変えないこと。

背景は「純粋なマゼンタ #FF00FF」の一色で完全に塗りつぶしてください。
ボディにマゼンタやピンク系の色を使わないでください。

同じロボットを2体、横に並べて描いてください。
・左: 目を細めて、体の下から勢いよく泡を吹いている（水中を上昇している姿）
・右: 目がぐるぐる回って気を失い、体が斜めに傾いている

【禁止】
文字・ロゴ・透かしを描かない。人物を描かない。背景に色を足さない。
```

### 7-4. 見るところ

1. 背景が本当に一色のマゼンタか（グラデーションが乗っていると抜けない）
2. オブジェクトの中にピンク系の色が混ざっていないか
3. 文字が写り込んでいないか
4. 小さくして形が読めるか。ゲーム中の実寸は 40〜110px 程度
5. ろぼとは、添付した元絵と同じロボットに見えるか

噴射中の絵に付いてくる泡の尾と、気絶の絵の渦巻きは、位置の基準がずれるので
こちらで本体だけ切り出している（泡はゲーム側で描いている）。
