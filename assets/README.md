# arial — サイト素材

`image/` の3枚（キャラクター設定シート / アイコン / ろぼと）から書き出した素材一式。
PNG はすべて背景透過、同名の `.webp`（可逆圧縮）を併置しているので、`<picture>` で
WebP を先に、PNG をフォールバックにするとよい。

## characters/ — arial 本人

| ファイル | サイズ | 用途 |
|---|---|---|
| `arial-full-scene.jpg` / `.webp` | 321×976 | 全身立ち絵（水の背景つき）。Hero の主役ビジュアル |
| `arial-half-talk.png` | 234×296 | 上半身・口を開けた表情。**透過**。Hero や CTA に重ねる用 |
| `arial-half-point.png` | 236×296 | 上半身・指差しポーズ。**透過**。導線の指し示しに |
| `arial-bust-framed.jpg` | 326×287 | バストアップ（水の輪の背景つき）。About のメイン画像 |
| `arial-face-framed.jpg` | 325×287 | 顔アップ（同上）。プロフィールカード用 |

### characters/angle/ — 角度差分（すべて透過, 約190〜255px）
`arial-angle-1`（左向き）→ `-5`（後ろ姿）。スクロール演出やセクション見出しの
アクセントに。1〜4 が顔の向き違い、5 が後ろ姿。

### characters/face/ — 表情差分（すべて透過, 約110×120px）
設定シートのラベルに合わせた命名。

`arial-normal`（通常） / `arial-smile`（笑顔） / `arial-smile-closed`（目閉じ笑顔） /
`arial-surprised`（驚き） / `arial-angry`（怒り） / `arial-sad`（悲しみ） /
`arial-troubled`（困り） / `arial-shy`（照れ） / `arial-wink`（ウィンク） /
`arial-singing`（歌唱）

> 名前は設定シートのラベルに準拠。絵の印象とラベルが少しずれているものがあるので
> （「驚き」が穏やかめ、など）、実際に使う際は画を見て割り当て直してよい。

### characters/chibi/ — ミニキャラ（すべて透過, 約105×140px）
`arial-chibi-1` 〜 `-6`。ローディング、404、フッター、通知バナー、
配信スケジュールの吹き出しなど、軽い場所に。

## roboto/ — 相棒「ろぼと」

| ファイル | サイズ | 用途 |
|---|---|---|
| `roboto.png` | 366×448 | 吹き出しなし。**推奨**。セリフは HTML 側で描くと文言を差し替えられる |
| `roboto-hello.png` | 438×448 | 元絵のまま（"Hello!" の吹き出しつき） |
| `roboto-bubble.png` | 192×182 | 吹き出しだけ |

`roboto.png` は元絵で吹き出しの尻尾が頭の角に重なっていたため、頭部の左右対称性を
使って右上の角を復元してある。

## meta/ — ファビコン・アイコン・OGP

| ファイル | 用途 |
|---|---|
| `favicon.ico` (16/32/48) | 旧来のブラウザ向け |
| `favicon-16/32/48.png` | 顔をタイトにトリミング。小サイズでも顔と分かる |
| `icon-192.png` / `icon-512.png` | PWA マニフェスト |
| `apple-touch-icon-180.png` | iOS ホーム画面 |
| `ogp.png` / `ogp.jpg` (1200×630) | **暫定版**。キャッチコピーが決まったら差し替える |

## palette.css
設定シート下部の公式カラーパレット7色を実測して CSS 変数にしたもの。
ろぼとのボディカラーも追加してある。
